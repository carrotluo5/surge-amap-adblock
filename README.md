# 高德地图去广告（Surge 模块）

一个自己用的高德去广告模块。不拦域名，只是在高德 App 拉数据的时候，把响应体里的广告字段删掉：开屏、首页和「我的」页的推广卡、搜索热词、消息横幅、AI 推荐流、打车页弹窗。地图和导航的正常接口不碰。

## 安装

Surge → 首页 → 模块 → 安装新模块，粘贴：

```
https://raw.githubusercontent.com/carrotluo5/surge-amap-adblock/main/amap.sgmodule
```

装完检查三件事：模块列表里出现「高德地图去广告」并且已启用；Surge 的 CA 证书已安装、被系统信任（模块会把 `m5.amap.com`、`m5-zb.amap.com`、`sns.amap.com`、`oss.amap.com`、`ai.amap.com` 追加进 MITM）；然后杀掉高德重开。

## 覆盖范围

45 条接口，按 host 拆成 5 条脚本：

| 脚本 | host | 管什么 |
|---|---|---|
| 高德地图去广告-主接口 | m5.amap.com | 首页卡片、开屏、推荐瀑布流、搜索热词与结果、POI 详情、消息、导航插播、打车/公交、酒店、profile 页 |
| 高德地图去广告-消息 | sns.amap.com | 消息盒子 |
| 高德地图去广告-打车 | m5-zb.amap.com | 打车订单页、营销弹窗 |
| 高德地图去广告-横幅 | oss.amap.com | 横幅列表 |
| 高德地图去广告-AI推荐流 | ai.amap.com | 首页和探索页的 AI 流 |

拆开是没办法的事：Surge 的 `pattern` 匹配整条 URL，host 和 path 绑在一起，合成一条容易误伤或者漏掉。

## 大概怎么做的

大部分接口是字段级删除。`JSON.parse` 之后把广告节点删掉，其余原样返回。

首页和「我的」页不太一样，它们不是删几个字段，而是**从某张卡开始，下面全都不要**。首页顺着 `cardList` 找叫车卡（空气清新的车 / 叫一辆 / 臭车），找到就截断；「我的」页找到「达人任务」就截断。万一哪天文案改了没命中，会退到一份安全白名单卡片，不至于把整页清空。

AI 推荐流是 SSE 文本流，逐行过，命中叫车行之后的内容丢掉。服务端自己的结束帧原样保留，不自己造帧——伪造的帧格式对不上，App 会直接报「网络不畅」。

开屏广告简单，把广告数组清空就行。

整段逻辑包在 `try/catch` 里，任何分支出错就 `$done({})` 原样放行。Surge 脚本里一次没接住的异常，就等于这个模块失效了，宁可少删。

## 已知问题

- 首页偶尔还会冒一两张卡，或者出现「网络不畅，请稍后重试」，一般是某个接口还没覆盖到，抓到路径补上就好。
- 底部 tab 和搜索页的分类行是原生渲染，响应体里根本没有，脚本改不了。
- 响应体超过 `max-size=1048576` 会被跳过，防止 iOS 网络扩展内存超限。
- 同时开别的去广告模块可能冲突，Surge 一个响应只会跑第一条命中的脚本。

## 出处

字段级的改写逻辑来自 RuCu6 / ddgksf2013 的公开脚本（原地址已经 404，现存镜像是 `lugu123/Loon/Scripts/Amap_remove_ads.js`）。首页 AI 流和「我的」页的几个新 key，参考了 `yisaings/surge` 的抓包结论。
